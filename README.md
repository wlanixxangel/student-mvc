# Student MVC

Учебный PHP-проект, демонстрирующий MVC и работу с MySQL.

## Требования
- PHP 8.x с расширением PDO MySQL
- MySQL или MariaDB

## Запуск
1. Создать базу students_db и таблицу users.
2. Скопировать config/database.example.php в config/database.php.
3. Указать локальные параметры подключения.
4. Настроить корень сайта на каталог public.
5. Открыть index.php в браузере.
